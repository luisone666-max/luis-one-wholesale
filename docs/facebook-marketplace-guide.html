Facebook / Marketplace 商品发布操作方法

目标是把 Luis One Supply Hub 网站商品更快推到 Facebook。正确做法是： Meta Catalog 用官方 feed 自动同步；Marketplace 用脚本生成发布包，然后人工粘贴发布。

不要做自动登录 Facebook 自动发 Marketplace 的脚本。 这种模拟点击不稳定，也容易触发 Facebook 风控。我们只做正规同步和低风险辅助发布。

总流程图

方案 A：Meta Catalog 官方同步

1. 使用网站 feed 网站自动输出 CSV：
https://luisonesupplyhub.com/meta/catalog-feed.csv
2. 打开 Commerce Manager 进入 Catalog → Data sources → Data feed → Scheduled feed。
3. 看 Diagnostics 同步后检查 Meta 是否拒绝商品，重点看图片、价格、标题和库存。

方案 B：Marketplace 发布包

1. 批量导出 脚本生成 facebook-marketplace-posts.csv，每个商品一行。
2. 复制资料 复制标题、零售价、描述、图片链接、网站链接、Messenger 话术。
3. 人工发布 在 Marketplace 新建 listing，分类选 Vehicle Parts & Accessories，地点选 Manila。

我建议做到网站后台

后台加两个功能：一个是批量导出 Marketplace CSV；一个是每个商品旁边有 Copy for Marketplace 按钮。这样你可以快速人工发布，不需要冒险自动发帖。
